Microsoft C++ Standard Library（NicoBE GPU描画DLL）
ライセンス: Apache License 2.0 with LLVM Exception
Copyright (c) Microsoft Corporation.
https://github.com/microsoft/STL/blob/main/LICENSE.txt

Microsoft Visual C++ランタイム（NicoBE GPU描画DLL）
/MTで静的リンクしています。Microsoft Visual Studioの再頒布条件に従うコンポーネントです。NicoBEのMITライセンスに変更するものではありません。

Windows API / Direct3D / Direct2D / DirectWrite / DirectComposition / Windows Imaging Component
Windowsに含まれるAPIを使用します。これらのOSコンポーネントは本アプリのMITライセンスの対象ではなく、Microsoftの提供条件に従います。GPU描画DLLのNicoBE独自コードはMITです。

FFmpeg 9.0.2（NicoBEのMKV読み取り）
FFmpegプロジェクトのライブラリをLGPL 2.1以降の条件で利用し、mkvフォルダ内のavformat、avcodec、avutilに動的リンクします。
ライセンス文書はmkvフォルダ、DLLに対応するソースと再ビルド手順は同時配布のNicoBE-MKV-Source.zipにあります。
公式ソース: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
配布指針: https://ffmpeg.org/legal.html

zlib 1.3.2（MKV内の圧縮字幕の展開）
展開部分をavformatに静的リンクします。zlibライセンス文書はmkvフォルダに収録しています。

FFmpeg / ffprobe（NicoBE Encoderが別プロセスとして実行する外部ソフト）
EncoderのZIPには同梱しません。ダウンロード機能はGyanのessentialsビルドを取得します。この配布ビルドはGPLv3です。手動で指定したFFmpegはビルド構成によりライセンスが異なります。
導入した配布フォルダに含まれるLICENSEやdocの記載を確認してください。ダウンロード時に同梱文書も保持します。FFmpeg内部のエンコーダーなどは本アプリに直接リンクしていません。
配布元・構成ライブラリ・対応ソースへのリンク:
https://www.gyan.dev/ffmpeg/builds/
FFmpegライセンス案内:
https://ffmpeg.org/legal.html
FFmpegソースコード:
https://github.com/FFmpeg/FFmpeg

MPC-BE / NicoJK
連携先のアプリ／ログ形式です。本アプリのライブラリとして組み込んでいません。各ソフトのライセンスは各配布元をご確認ください。
https://github.com/Aleksoid1978/MPC-BE
